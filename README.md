# clock-lab — preprints

*Transported cell-composition corrections of epigenetic age can add the
confounding they are meant to remove* — Luan Ivepe, independent researcher.

- `preprint_en.pdf` — English, the reference version
- `preprint_pt.pdf` — Portuguese translation

`src/` holds the Typst sources, references and figures:

    cd src && typst compile manuscript.typ ../preprint_en.pdf
    cd src && typst compile manuscript_pt.typ ../preprint_pt.pdf

Code, data provenance and the stage-by-stage record of the analysis, including
every conclusion a later stage overturned, are at
<https://github.com/KTHimiko/clock-lab>.

## How this was made

This study was carried out with extensive use of an AI system, Claude
(Anthropic), through Claude Code. The AI wrote the analysis code, designed and
ran the analyses, searched the literature and drafted the text and figures. The
author set the aims, chose which questions to pursue and what to report, brought
in critical readings of the drafts, and is responsible for the content. The
manuscript's Declarations section says the same.
