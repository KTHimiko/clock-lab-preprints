# clock-lab — preprints

Dois preprints do projeto clock-lab (rascunhos, não submetidos):

- `preprint_en.pdf` — *Transported cell-composition corrections of epigenetic age
  can add the confounding they are meant to remove* (versão de referência)
- `preprint_pt.pdf` — versão em português

`src/` tem as fontes em Typst, as referências e as figuras. Para recompilar:

    cd src && typst compile manuscript.typ ../preprint_en.pdf
    cd src && typst compile manuscript_pt.typ ../preprint_pt.pdf
